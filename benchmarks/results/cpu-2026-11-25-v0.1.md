# CPU results, 2026-11-25 (v0.1)

The numbers the v0.1 README and docs quote. Taken on a quiet 4-core VM: nothing else was
running, the 1-minute load average was 0.8 at the start and 1.2–3.4 during the run (the
benchmark's own processes; per-port values are in the JSON as `load_average_before` /
`_after`). Every port at its default CPU config, 25 interleaved rounds per measure. A
speedup is real only where the IQR range stays on one side of 1.

**CPU**: Intel(R) Xeon(R) Processor @ 2.30GHz (4 of 4 cores usable). JAX 0.12.1 (jaxlib 0.12.1), Python 3.14.6, expex c9fe6a12a; 2026-11-25 11:23:28 UTC; load average at start 0.8.

Best of N interleaved runs, each after a warm-up, ending in `block_until_ready`. Speedup = original time / port time (above 1: the port is faster); the range pairs the original's quartiles with the port's opposite ones. Compile = trace + lower + XLA compile from cold caches, best of the repeats; * = estimated as first call minus the median call (for callables that are not one `jax.jit`).
